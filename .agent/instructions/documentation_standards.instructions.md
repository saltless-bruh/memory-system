# Documentation Standards — SNP Memory System

1. **Frontmatter Schema**:
   - All wiki notes MUST contain: `type`, `title`, `summary`, `entities`, `department`, `sources`, `last_compiled`.
   - `summary` MUST be concise, assertive, and exactly ONE sentence.

2. **Body Structure**:
   - Mandatory sections: `## TL;DR`, `## Technical Specifications`, `## Provenance`, `## Cross-References`.

3. **Links**:
   - Use `[[wikilink-slug]]` syntax for inter-page references.
   - Do NOT use `related:` in frontmatter.
