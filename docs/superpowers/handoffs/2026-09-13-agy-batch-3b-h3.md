## 3 · The qualifier

This is the mirror image of the Batch 3 pilot. There, sharpening
`AI Technical Diagram Generation.md` **stopped** it squatting on an unrelated
query, and recall rose. Here, sharpening a category page **made** it squat on
its own exemplar's query.

```
  A SPECIFIC page (an entity, a tool, a CVE)
    name it, version it, number it  ─────────────▶  it wins its own queries ✓

  A CATEGORY page (a concept, a pattern, a comparison)
    name its exemplars in chunk 0  ──────────────▶  it outranks their pages ✗
    describe the CATEGORY instead  ──────────────▶  both stay findable ✓
```

So the rule gains one clause:

> Carry the page's own distinctive terms. On a **category or concept** page,
> the distinctive terms are what makes the *category* specific — its defining
> property, its scope, what distinguishes it from neighbouring categories —
> **not a list of the products that belong to it.** Naming an exemplar in
> chunk 0 puts the category page into competition with that exemplar's own page,
> and the category page usually wins, which is the wrong outcome.

Mention exemplars in the body, where they support `[[wikilinks]]` and cannot
displace chunk 0. This is consistent with what you were already told: the TL;DR
is the first text scored, so it should say what *this page* is, and a category
page is not its examples.
