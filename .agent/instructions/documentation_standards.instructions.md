# Documentation Standards — SNP Memory System V3

1. The target vault's `SCHEMA.md` is authoritative.
2. New pages use `title`, `created`, `updated`, `type`, `tags`, `sources`, and
   `confidence`, with optional `contested`, `contradictions`, and capture
   metadata.
3. Every page has an H1 and `## Cross-References`. `## TL;DR` is recommended;
   `## Provenance` is required when sources exist. Interior H2 sections are
   free-form.
4. Use at least two outbound `[[wikilinks]]` and no parallel relationship field.
5. Preserve authored catalogue descriptions and editorial logs. Do not
   regenerate them from incomplete metadata.
6. The current automated checker is narrower than this V3 contract. Record the
   manual schema/heading review rather than overstating automation.
